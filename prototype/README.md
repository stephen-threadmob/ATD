# Prototype

`atd-prototype.html` is a single self-contained file — no build, no server, no network.
Open it in any browser.

It is **not** a mockup. The day it shows was generated by calling `atd.find_slots()` and
`atd.create_booking()` against a live PostgreSQL 16 database with the real migrations and
seed applied, then exported to JSON and embedded. Three bookings the generator originally
asked for were refused because the facility was genuinely full at those times.

Regenerate after changing the seed or catalogue:

```bash
./scripts/db-reset.sh                 # migrations + seed, incl. 03_demo_day.sql
# re-run the two export queries, then:
python3 - <<'PY'
import json, pathlib
tpl = pathlib.Path('prototype/template.html').read_text()
pathlib.Path('prototype/atd-prototype.html').write_text(
  tpl.replace('__STATIC__', json.dumps(json.load(open('/tmp/atd_static.json'))))
     .replace('__DAY__',    json.dumps(json.load(open('/tmp/atd_day.json')))))
PY
```

`template.html` is the source; the built file is the template with the two JSON payloads
substituted in.

## What the prototype covers

| Tab | Shows |
|---|---|
| Website | The public site: services with plain-English resource needs, live camp fill rates, coaches with real qualifications, party packages, memberships |
| Book a Lesson | The parent flow at phone width, with a live hold countdown and the slot-taken race |
| My Account | The customer portal, switchable across all eight demo households: next booking, balances, package credits, participants, waivers, registrations, and a cancellation that shows the policy outcome *before* confirming |
| Master Calendar | Resource timeline, buffers, sibling highlighting across lanes, booking drawer |
| Front Desk | Today's operations board driven by the real day's data |
| Coach | A coach's own day, and the data they are denied |
| Service Builder | Every seeded service and the resources it declares |
| How it works | The exclusion constraint, and what the test suite proves |

The three programs on the Website tab (summer camp, arm-care block, Parents' Night
Out) were materialised through `atd.materialize_program_sessions()`, so each session
really reserves its cages, coaches and lobby space — the camp alone holds 32
reservations across four mornings. Fill rates and the waitlist state are counted from
actual registrations.

## Colour

Eight service categories fold into five colours. The eight-colour set failed the
colourblind-separation check on pairs that can sit side by side on a timeline
(worst pair ΔE 3.2 under deuteranopia). The five-colour set passes on all pairs.
Every block also carries its service name, so identity is never colour-alone.
Light mode only — no dark set on this ramp clears the all-pairs floors, and a dark
mode that fails validation is worse than none.
